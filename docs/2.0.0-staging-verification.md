## What remains unverified

- Installation and operation on a real hosting provider, Apache/Nginx virtual host and the provider's exact PHP/MySQL configuration.
- Independent penetration testing and a security assessment against a live deployment.
- Real-world backup scheduling and recovery on the eventual hosting account.
- Production readiness of the optional COD shop for any particular business process.

No domain or hosting account is currently available, so deployment verification is intentionally pending. A green CI run and a valid staging archive are not represented as proof of production certification.
